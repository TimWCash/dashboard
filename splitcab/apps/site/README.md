# SplitCab website

Static pages the app stores require: privacy policy, terms, support and account deletion.
Deploy the folder to any static host at the domain you set as `SITE_URL` (the app and store listing link to `/privacy`, `/terms`, `/support` and `/delete-account`; configure the host to serve `privacy.html` at `/privacy` and so on, which Vercel, Netlify and Cloudflare Pages do by default with clean URLs).

**The privacy policy and terms are drafts.** Have a solicitor review them and fill in every highlighted placeholder (company name, address, CRO number, contact addresses, dates, store links) before publishing.
